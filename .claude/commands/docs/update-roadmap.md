# Claude 명령어: Update Roadmap

완료된 작업을 ROADMAP.md에 체크하고 진행 상황을 업데이트합니다.

## 사용법

```
/update-roadmap
```

## 프로세스

1. ROADMAP.md 파일 읽기
2. 사용자에게 완료한 Task 번호 확인
3. 해당 Task 제목에 ✅ 추가
4. Phase 진행 상황 업데이트
5. 문서 버전 및 최종 업데이트 날짜 갱신
6. 진행 상황(X/12 Tasks 완료) 업데이트

## 업데이트 규칙

### Task 체크 패턴

**Task 제목 업데이트:**

- Before: `- **Task N-M: 작업명**`
- After: `- **Task N-M: 작업명** ✅`

**하위 항목:**

- 📋 작업 내용과 `완료 기준:`, `의존:`, `관련 PRD:`, `주의:` 메모는 변경하지 않는다.
- Task는 작업의 최소 단위(원자 단위)이므로 완료 표시는 제목 끝의 ✅ 하나로만 한다.

### Phase 상태

- 모든 Task 완료 시: `### Phase N: 제목` → `### Phase N: 제목 ✅`

### 진행 상황 업데이트

- 완료된 Task 수 / 전체 Task 수 계산
- 진행 상황 라인 업데이트

### 날짜 업데이트

- 최종 업데이트 날짜를 오늘 날짜로 자동 설정

## 대화형 프로세스

1. 현재 ROADMAP.md 읽기
2. 미완료 Task 목록 표시
3. "어떤 Task를 완료했나요? (예: 1-4 또는 1-4,1-5)" 질문
4. 사용자 입력 받기
5. 해당 Task 제목에 ✅ 추가
6. Phase 상태 자동 확인 및 업데이트
7. 진행 상황 통계 업데이트
8. 변경 사항 확인 메시지 출력

## 구현 상세

### Task 완료 체크 로직

1. **Task 제목 찾기**: `- **Task N-M:` 패턴(N = Phase 번호, M = Phase 안의 순번)으로 검색
2. **이미 완료 확인**: 제목에 ✅가 있으면 건너뜀
3. **제목 업데이트**: 제목 끝에 ✅ 추가 (하위 항목은 수정하지 않음)

### Phase 완료 체크 로직

1. Phase 내 모든 Task 확인
2. 모든 Task에 ✅가 있으면 Phase 제목에도 ✅ 추가
3. 단, 이미 ✅가 있는 Phase는 건너뜀

### 진행 상황 계산

```
전체 Task: 1-1 ~ 마지막 Phase의 마지막 Task (예: 12개)
완료 Task: ✅ 표시가 있는 Task 개수
진행률: (완료 Task / 전체 Task) * 100
```

## 예시

**Before:**

```markdown
- **Task 1-4: 공통 컴포넌트 라이브러리 구축**
  - 📋 shadcn/ui 설치 및 설정
  - 📋 기본 UI 컴포넌트 추가
  - 📋 더미 견적서 데이터 생성 유틸리티
  - 완료 기준: 공통 컴포넌트가 예시 페이지에서 렌더링되고 빌드가 통과한다
  - 의존: Task 1-3
  - 관련 PRD: PRD.md 3.2 공통 UI
  - 주의: [구현] 컴포넌트는 props 타입을 명시할 것

**📅 최종 업데이트**: 2025-10-07
**📊 진행 상황**: Phase 1 완료 (3/12 Tasks 완료)
```

**After:**

```markdown
- **Task 1-4: 공통 컴포넌트 라이브러리 구축** ✅
  - 📋 shadcn/ui 설치 및 설정
  - 📋 기본 UI 컴포넌트 추가
  - 📋 더미 견적서 데이터 생성 유틸리티
  - 완료 기준: 공통 컴포넌트가 예시 페이지에서 렌더링되고 빌드가 통과한다
  - 의존: Task 1-3
  - 관련 PRD: PRD.md 3.2 공통 UI
  - 주의: [구현] 컴포넌트는 props 타입을 명시할 것

**📅 최종 업데이트**: 2025-10-08
**📊 진행 상황**: Phase 2 진행 중 (4/12 Tasks 완료)
```

## 주의사항

- Task 번호는 `{Phase}-{순번}` 형식 (1-1, 1-2, 2-1...)이며, 순번은 각 Phase 안에서 1부터 시작한다. `Task 001` 같은 평탄 번호는 쓰지 않는다. ROADMAP.md에 옛 형식이 남아 있으면 먼저 Phase 제목 아래 나열 순서대로 새 형식으로 바꿀지 사용자에게 확인한다.
- 이미 완료된(✅ 표시가 있는) Task는 건너뜀
- Phase 전체 완료 시 Phase 제목에도 ✅ 추가
- 날짜는 YYYY-MM-DD 형식 사용
- 여러 Task 동시 완료 지원 (1-4,1-5,2-1)

## 스마트 기능

1. **자동 Phase 진행 추적**
   - Phase 1 완료
   - Phase 2 진행 중
   - Phase 4 대기 중

2. **완료율 계산**
   - 전체 12개 Task 중 완료 개수 자동 카운트
   - Phase별 완료 Task 수 추적

3. **날짜 자동 갱신**
   - 오늘 날짜로 자동 업데이트 (YYYY-MM-DD)

## 사용 예시

```bash
# 커맨드 실행
/update-roadmap

# 출력 예시:
현재 미완료 Task 목록:
- Task 1-4: 공통 컴포넌트 라이브러리 구축
- Task 1-5: 견적서 조회 페이지 UI 구현
- Task 2-1: 에러 및 로딩 상태 UI 구현
...

어떤 Task를 완료했나요? (예: 1-4 또는 1-4,1-5): 1-4

✅ Task 1-4 완료 체크 완료!
📊 진행 상황: 4/12 Tasks 완료 (33%)
```
