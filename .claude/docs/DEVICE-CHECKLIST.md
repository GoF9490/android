# 실기기 수동 검증 체크리스트 (Task 7-2)

에뮬레이터로 확인할 수 없는 항목을 실기기에서 직접 확인하기 위한 문서다. 이 문서의 검증은 사용자만 수행할 수 있다. 결과는 각 항목의 결과 칸에 기입한 뒤 전달한다. 전달받은 결과만 PRD §17에 기록하며, 수행하지 않은 항목은 "미수행"으로 남긴다.

근거: `.claude/docs/PRD.md` §12.1·§12.3·§13·§17, `.claude/docs/ROADMAP.md` Task 7-2.

## 0. 주의 사항

* **토큰(JWT)과 딥링크 URI(`musicapp://oauth2/callback?token=...`)를 스크린샷·로그·메모·채팅에 남기지 않는다.** `adb logcat`을 공유해야 하면 `token=` 이 포함된 줄을 지우고 전달한다.
* 실제 Google 계정으로 로그인하므로 개발용 계정을 쓰는 것을 권장한다.
* 업로드·다운로드는 개발 서버 데이터를 바꾼다. 테스트용 파일을 쓰고 끝난 뒤 정리한다(삭제 기능이 앱에 없으면 서버 관리자에게 요청).
* 문제가 있으면 항목의 "메모"에 재현 순서, 기기 모델, Android 버전을 적는다.

## 1. 준비

### 1.1 기기

1. 기기에서 설정 > 휴대전화 정보 > 빌드 번호를 7번 눌러 개발자 옵션을 켠다.
2. 설정 > 개발자 옵션 > **USB 디버깅**을 켠다.
3. USB 케이블로 PC에 연결하고 기기에 뜨는 "USB 디버깅 허용"을 승인한다.
4. PC 터미널(PowerShell 또는 Git Bash)에서 확인한다.

```
adb devices
```

기기가 `device`로 보여야 한다(`unauthorized`면 기기에서 허용을 다시 승인).

### 1.2 서버 연결 (`adb reverse`)

PC에서 docker 스택(Nginx 80, 백엔드, RustFS, PostgreSQL)이 떠 있어야 한다. 그런 다음 실행한다.

```
adb reverse tcp:80 tcp:80
adb reverse --list
```

목록에 `tcp:80 tcp:80`이 보이면 된다. **기기를 다시 연결하거나 USB를 뽑았다 꽂으면 다시 실행한다.**
앱의 `BASE_URL`은 `http://localhost`다. `10.0.2.2`나 PC 사설 IP로는 Google 로그인이 실패할 수 있으니 쓰지 않는다(PRD §12.3).

확인: 기기 Chrome에서 `http://localhost/` 를 열어 웹 화면이 나오는지 본다.

### 1.3 설치

PC 프로젝트 루트(`C:\WorkSpace\re-dubb\android`)에서 둘 중 하나로 설치한다. 기기가 하나만 연결되어 있어야 한다(여러 대면 `adb -s <시리얼>` 사용).

```
./gradlew installDebug          # Git Bash
.\gradlew.bat installDebug      # PowerShell
```

또는 APK를 직접 설치한다.

```
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

앱 실행: 홈 화면에서 앱 아이콘을 누르거나 `adb shell am start -n com.example.musicapp/.MainActivity`.
